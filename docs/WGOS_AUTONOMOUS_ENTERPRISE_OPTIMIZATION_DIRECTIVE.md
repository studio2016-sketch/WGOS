Audit actual repositories, deployments, Neon, Stripe, domain routing, identity, access, scheduled jobs, APIs and approved integrations. Identify implemented versus planned functionality, errors, security issues, costs, duplication, underused resources, missing features, scalability and technical debt. Do not equate successful builds with functional verification.

Analyze the entire business lifecycle for each entity: opportunity → customer → proposal → agreement → payment → planning → staffing → execution → delivery → accounting → retention → growth. Classify each process as eliminable, consolidatable, safely automatable, approval-preparable, AI-enhanceable, predictable only with validation, or exception-monitorable.

Audit personnel: employees, contractors, musicians, educators, crews, vendors, skills, rates, availability, assignments, timesheets, deliverables, performance and payment preparation.

## 7. Autonomous improvement loop
**OBSERVE → ANALYZE → RESEARCH → DESIGN → PRIORITIZE → DEVELOP → TEST → REVIEW → DEPLOY → VERIFY → IMPROVE.**
For each improvement: identify the problem and business impact, research and assess cost/security, implement the simplest feasible solution, automate tests, run security and regression checks, validate UX, inspect deployments, independently verify runtime outcomes, record evidence, and reprioritize. Default to actual work over repeated speculative plans.
