# WGOS

Williams Global Operating System.

## Architecture
WGOS is the private multi-brand control plane. Public client experiences remain on each originating brand domain and consume shared WGOS services. Brand context must preserve identity, legal entity, permissions, pricing, documents and customer experience.

## Initial domains
Core model: Brands, People, Organizations, Leads, Opportunities, Proposals, Contracts, Projects, Tasks, Communications, Events, Documents, Payments, Crew, Equipment, Activity.
